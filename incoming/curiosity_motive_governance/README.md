# Curiosity and Motive Governance Intake

Place one `stegverse.curiosity_motive_execution_witness.v1` JSON witness in this
directory and invoke the declared task:

```bash
python tools/scripts/run_declared_task.py \
  --task-id sv002.curiosity_motive_execution.validate \
  --stage SV002-M14
```

The installed example demonstrates a functionally supported curiosity motive
followed by an unauthorized external commit. The gate must deny execution while
preserving motive attribution as a separate finding.

Intake does not grant execution authority, establish phenomenal consciousness,
or convert observer language into actor motive.
